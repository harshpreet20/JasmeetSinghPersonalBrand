## Phase 1: Supabase Setup

### 1.1 Create Supabase Project
1. Go to [supabase.com](https://supabase.com)
2. Create new project
3. Choose region closest to your users (India recommended)
4. Set a strong password for postgres user
5. Wait for project to initialize (2-3 minutes)

### 1.2 Get Credentials
In Supabase Dashboard:

1. **Project URL & Keys:**
   - Settings → API → Project Settings
   - Copy `Project URL` → `NEXT_PUBLIC_SUPABASE_URL`
   - Copy `anon public key` → `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - Copy `service_role secret` → `SUPABASE_SERVICE_ROLE_KEY`

2. **Example values:**
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://xyz.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   ```

### 1.3 Create Database Tables

Use SQL Editor in Supabase Dashboard:

```sql
-- Create all required tables
CREATE TABLE form_submissions (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  created_at TIMESTAMP DEFAULT NOW(),
  name VARCHAR(255) NOT NULL,
  email VARCHAR(255) NOT NULL,
  phone VARCHAR(20),
  problem_statement TEXT,
  source_page VARCHAR(255),
  status VARCHAR(50) DEFAULT 'new',
  admin_notes TEXT,
  data JSONB
);

CREATE TABLE chat_sessions (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  session_token VARCHAR(255) UNIQUE NOT NULL,
  messages JSONB DEFAULT '[]'::jsonb,
  visitor_name VARCHAR(255),
  visitor_email VARCHAR(255),
  page_url VARCHAR(500),
  converted_to_lead BOOLEAN DEFAULT false,
  lead_form_id BIGINT REFERENCES form_submissions(id),
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE chatbot_knowledge (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  category VARCHAR(100) NOT NULL,
  title VARCHAR(255) NOT NULL,
  content TEXT NOT NULL,
  is_active BOOLEAN DEFAULT true,
  sort_order INT DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE blogs (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  slug VARCHAR(255) UNIQUE NOT NULL,
  title VARCHAR(255) NOT NULL,
  meta_title VARCHAR(255),
  meta_description VARCHAR(255),
  target_keyword VARCHAR(255),
  content_html TEXT,
  content_draft TEXT,
  featured_image_url VARCHAR(500),
  author VARCHAR(255),
  tags TEXT[],
  status VARCHAR(50) DEFAULT 'draft',
  seo_score INT,
  aeo_score INT,
  geo_score INT,
  readability_score INT,
  ranking_probability INT,
  ai_citation_probability INT,
  seo_analysis_json JSONB,
  seo_analyzed_at TIMESTAMP,
  published_at TIMESTAMP,
  view_count INT DEFAULT 0,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Enable RLS
ALTER TABLE form_submissions ENABLE ROW LEVEL SECURITY;
ALTER TABLE chat_sessions ENABLE ROW LEVEL SECURITY;
ALTER TABLE chatbot_knowledge ENABLE ROW LEVEL SECURITY;
ALTER TABLE blogs ENABLE ROW LEVEL SECURITY;
```

## Phase 2: API Keys & Credentials

### 2.1 Get External API Keys

1. **Anthropic API Key**
   - Go to [console.anthropic.com](https://console.anthropic.com)
   - Create API key
   - Copy → `ANTHROPIC_API_KEY`

2. **SearchIntel API Key** (for blog SEO analysis)
   - Go to [searchintel.ai](https://searchintel.ai)
   - Sign up/login
   - Get API key from dashboard
   - Copy → `SEARCHINTEL_API_KEY`

3. **Site URL**
   - Decide on domain (e.g., jasmeetsingh.com)
   - Set → `NEXT_PUBLIC_SITE_URL`

### 2.2 Create Environment Files

Create `.env.local` (never commit this):
```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
SUPABASE_SERVICE_ROLE_KEY=eyJ...

# APIs
ANTHROPIC_API_KEY=sk-ant-...
SEARCHINTEL_API_KEY=your-key

# Site
NEXT_PUBLIC_SITE_URL=https://jasmeetsingh.com
```

**Security Note:** `.env.local` is in `.gitignore` - never commit credentials

## Phase 5: Vercel Deployment

### 5.1 Set Up Vercel Project
1. Go to [vercel.com](https://vercel.com)
2. Sign in with GitHub
3. Import the repository
4. Select `Next.js` framework
5. Click Deploy

### 5.2 Configure Environment Variables
In Vercel Dashboard → Settings → Environment Variables:

```
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
SUPABASE_SERVICE_ROLE_KEY=eyJ...
ANTHROPIC_API_KEY=sk-ant-...
SEARCHINTEL_API_KEY=...
NEXT_PUBLIC_SITE_URL=https://jasmeetsingh.com
```

**Important:** Mark `SUPABASE_SERVICE_ROLE_KEY` and `ANTHROPIC_API_KEY` as "Sensitive"

### 5.3 Deploy
1. Click "Deploy" button
2. Vercel builds and deploys automatically
3. Get production URL (e.g., `jasmeet-brand.vercel.app`)

### 5.4 Configure Domain
1. Go to Settings → Domains
2. Add custom domain (e.g., `jasmeetsingh.com`)
3. Update DNS records as instructed
4. Wait for SSL certificate (usually instant)

## Troubleshooting

### Issue: "SUPABASE_URL is required"
**Solution:**
1. Verify `.env.local` exists and has correct values
2. Check `NEXT_PUBLIC_SUPABASE_URL` is set
3. Restart dev server

### Issue: "Invalid API key"
**Solution:**
1. Re-copy key from Supabase Dashboard
2. Verify no extra spaces/newlines
3. Ensure using correct key (anon vs service_role)

### Issue: "CORS error" in frontend
**Solution:**
1. Verify Supabase CORS settings
2. Add domain to allowed origins
3. Check API request headers

### Issue: "Authentication required" error
**Solution:**
1. Verify RLS policies are set up correctly
2. Check user has authenticated role
3. Test with direct SQL: `SELECT * FROM form_submissions LIMIT 1;`

### Issue: Search operations slow
**Solution:**
1. Add indexes to frequently searched columns:
   ```sql
   CREATE INDEX idx_blogs_status ON blogs(status);
   CREATE INDEX idx_form_submissions_email ON form_submissions(email);
   ```
2. Enable connection pooling in Supabase
